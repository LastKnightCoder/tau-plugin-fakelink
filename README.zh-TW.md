# FakeLink

內文裡寫到另一篇文章或專案文件的標題時，FakeLink 會自動識別，並在下方加上一條點線。點一下就能跳到那一篇，不必再手動建立連結。例如你寫過一篇《遺忘曲線》，以後在別的文章裡寫到「遺忘曲線」，這四個字都能直接點擊。

文字仍是原來的文字，儲存、同步與匯出都不受影響。除了標題，也可以依小標題跳到對應小節，或順著一段相同的文字，找回寫過它的筆記。

## 開始使用

1. **安裝**：在外掛中心安裝「FakeLink」。
2. **允許讀取**：首次啟用會彈出「請求存取你的資料」，選擇「永遠允許」。FakeLink 只讀取內容，不會更動任何筆記。
3. **點擊標題**：開啟一篇文章，寫到過的標題下方會出現一條點線。點一下開啟那一篇；想先查看內容，將滑鼠停在標題上即可展開預覽。

資料庫較大時，外掛需要先掃描一遍標題，稍等片刻點線就會出現。

## 可以做什麼

- **依標題跳轉**：寫到「遺忘曲線」，點一下就開啟《遺忘曲線》。
- **同名時選一篇**：有多篇都叫「遺忘曲線」時，點一下會列出候選項目，每篇標示類型、標籤與建立日期。滑鼠停在某一篇上可先預覽，再點一下開啟。
- **跳到對應小節**：在設定裡勾選 H1 到 H6 想要的層級，其他筆記的小標題也能點擊。例如《遺忘曲線》裡有個小標題「間隔重複」，在別處寫到它，點一下就能跳到那一節。
- **找回寫過相同內容的筆記**：在設定裡開啟「正文短語」，兩篇內容中出現過同一段話時也會被標出來，點擊跳到另一篇的那一段。它挑選的是前後文也對得上、最值得回看的幾句，偶然相同的幾個字不算，也不會滿篇都是。
- **不記得哪裡能點**：按住 ⌘（Windows 上是 Ctrl），內文裡可點擊的詞會一起亮起來。

## 依習慣調整

連結的樣式與範圍，都在外掛詳情的「設定 › 虛擬連結」裡。

- **嫌連結太顯眼**：把「顯示方式」換成「隱形」，平時看不出來，滑鼠懸停或按住 ⌘ 才顯現。也可以換成「螢光筆」或「著色」。
- **想在卡片裡使用**：把「在哪些正文顯示」裡的「卡片」勾選起來，之後卡片裡寫到過的標題與相同短語也能點擊。
- **不想識別某一類筆記的標題**：在「從哪裡收錄標題」裡將它取消勾選。
- **只去某幾類筆記裡找相同句子**：在「從哪裡收錄正文」裡選擇。

## 常見問題

**寫了標題卻沒有點線？** 標題必須寫完整，英文還會區分大小寫，只寫「遺忘」不會被識別成《遺忘曲線》。一篇筆記也不會連結到自己的標題。

**有篇筆記就叫「總結」，為什麼沒被標出來？** 「總結」「定義」這類詞太常見，真的標出來會滿篇都是連結，因此會被略過。小標題也一樣：同一段裡先提到它所屬的那篇筆記，才會標出來，點擊後跳到那一篇的那一小節。

**裝好了卻一個連結都沒有？** 內容較多時外掛需要先建立索引，稍等一下。如果還是沒有，請到外掛詳情的「權限」裡確認已允許讀取，再於命令面板執行「FakeLink：重新建立索引」。

**停用外掛後，筆記會變嗎？** 不會。點線只是顯示效果，停用後就會消失，文字始終維持原樣。

**手機上能用嗎？** 不能，FakeLink 僅支援桌面端。
