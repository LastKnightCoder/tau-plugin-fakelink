# FakeLink

在 Tau 桌面主窗口读写笔记时，点一下正文里出现的文章或项目文档标题，就能打开对应内容；也可以按正文小标题跳到相应小节。文字仍是普通正文，保存、同步和导出都保留原文。

## 使用

1. 在带有文字装饰能力的 Tau 桌面开发版安装并启用插件，允许读取文章和项目文档。
2. 打开一篇文章或项目文档。正文里提到其他内容的标题时，标题下方出现点线，表示可以打开。悬停会提示将打开哪篇内容，按住 ⌘（Windows 上为 Ctrl）可以一次看到所有可点的标题。同名时在标题旁弹出候选菜单，显示类型、标签和创建时间。
3. 在插件详情的「设置」中选择显示方式（引用、隐形、荧光笔、着色）、从哪里收录标题和在哪些正文显示。勾选卡片后可以在卡片里使用虚拟链接。

在「匹配什么」中，默认只选「内容标题」。按需勾选 H1 至 H6，可以同时匹配多个级别，也可以只保留小标题。比如只勾选 H2，另一篇笔记里出现某个二级标题的完整文字时，点击就会跳到那一节。同名小节按所属笔记、级别和位置区分。嵌套在引用块等容器内的小标题会定位到所在的顶层块。匹配到小标题的文字用淡色显示，和内容标题区分开。

匹配区分大小写，跳过当前内容本身。相同起点有多个标题时优先完整的长标题。英文与数字默认按 ASCII 单词边界匹配，可以在设置里关闭。标题可以跨加粗等文字格式，代码和已有行内链接会隔开匹配范围。新建、改名或删除目标后，索引随资料变化更新。命令面板中的「FakeLink：重新建立索引」可以手动重建索引。

## 正文短语

在「从哪里收录正文」中选择卡片、文章或项目文档，再开启「正文短语」。这些类型可以任意组合，和「在哪些正文显示」分别设置。例如只收录文章正文，同时只在卡片中显示，就能从卡片里的短语跳到提过它的文章。已有设置升级时，正文收录范围沿用卡片。

将指针停在标记上，可以预览目标正文；匹配小标题或短语时，从对应段落开始显示。匹配到多个目标时，点击标记打开候选列表，停在具体候选上即可预览。

打开内容时，共有的连续短语会在原文中标出。点击只有一个匹配的短语，直接打开对应段落；多个匹配时，按类型、标题和原句选择。标题匹配与正文短语重叠时优先打开标题。

匹配按连续原文进行，至少四个字母、数字或汉字，跳过自身、纯数字和过于常见的片段。索引在后台分页构建，只驻留当前工作区内存，结果逐步出现；新增、改写或删除内容后只更新涉及的条目。

## 本地构建

项目使用 npm 上的 Tau 插件 SDK 0.60.0。在插件仓库根目录执行：

```sh
pnpm install --frozen-lockfile
pnpm test
pnpm build
```

安装包位于 `dist/tau.fakelink-0.1.0.zip`。开发版 Tau 的插件页支持在「⋯」中选择「从 ZIP 安装」。普通发行版需随宿主发布这项能力后使用。
