# FakeLink

正文里写到另一篇文章或项目文档的标题时，FakeLink 会认出来，给它加上一条点线。点一下就跳到那一篇，不用再自己加链接。比如你写过一篇《遗忘曲线》，以后在别的文章里写到「遗忘曲线」，这四个字都能点。

文字还是原来的文字，保存、同步和导出都不受影响。除了标题，也可以按小标题跳到某一节，或者顺着一段相同的文字，找回写过它的笔记。

## 开始使用

1. **安装**：在插件中心安装「FakeLink」。
2. **允许读取**：第一次启用会弹出「请求访问你的数据」，选「始终允许」。FakeLink 只读取内容，不会改动任何笔记。
3. **点标题**：打开一篇文章，写到过的标题下面会多出一条点线。点一下打开那一篇；想先看看内容，把鼠标停在标题上，会展开预览。

资料库比较大时，插件要先把标题读一遍，稍等片刻点线才会出现。

## 可以做什么

- **按标题跳转**：写到「遗忘曲线」，点一下就打开《遗忘曲线》。
- **同名时选一篇**：有好几篇都叫「遗忘曲线」时，点一下会列出候选，每篇标着类型、标签和创建日期。停在某一篇上可以先预览，再点一下打开。
- **跳到某一节**：在设置里勾选 H1 到 H6 中想要的级别，其他笔记的小标题也能点。比如《遗忘曲线》里有个小标题「间隔重复」，在别处写到它，点一下就跳到那一节。
- **找回写过同样话的笔记**：在设置里打开「正文短语」，两篇内容里出现过同一段话时也会被标出来，点了跳到另一篇的那一段。它挑的是前后文也对得上、最值得回看的几句，偶然相同的几个字不算，也不会满篇都是。
- **不记得哪里能点**：按住 ⌘（Windows 上是 Ctrl），正文里能点的词会一起亮起来。

## 按习惯调整

链接的样子和范围，都在插件详情的「设置 › 虚拟链接」里。

- **嫌链接太显眼**：把「显示方式」换成「隐形」，平时看不出来，鼠标停上去或按住 ⌘ 才显出。也可以换成「荧光笔」或「着色」。
- **想在卡片里用**：把「在哪些正文显示」里的「卡片」选上，之后卡片里写到过的标题和相同的话也能点。
- **不想认某一类笔记的标题**：在「从哪里收录标题」里把它去掉。
- **只去某几类笔记里找相同的句子**：在「从哪里收录正文」里选。

## 常见问题

**写了标题却没有点线？** 标题要写全，英文还区分大小写，只写「遗忘」不会被认成《遗忘曲线》。一篇笔记也不会链接它自己的标题。

**有篇笔记就叫「总结」，为什么没被标出来？** 「总结」「定义」这类词太常见，真标出来会满篇都是链接，所以会被跳过。小标题也一样：同一段里先提到它所属的那篇笔记，才会标出来，点了跳到那一篇的那一节。

**装好了却一个链接都没有？** 内容多时插件要先把标题读一遍，稍等一会儿。还是没有的话，到插件详情的「权限」里确认已经允许读取，再在命令面板里运行「FakeLink：重新建立索引」。

**停用插件后，笔记会变吗？** 不会。点线只是显示效果，停用后就消失，文字一直是原来的样子。

**手机上能用吗？** 不能，FakeLink 只在电脑上可用。
