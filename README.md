# FakeLink

在 Tau 桌面主窗口读写笔记时，点一下正文里出现的文章或项目文档标题，就能打开对应内容；也可以按正文小标题跳到相应小节。文字仍是普通正文，保存、同步和导出都保留原文。

## 使用

1. 在带有文字装饰能力的 Tau 桌面开发版安装并启用插件，允许读取文章和项目文档。
2. 打开一篇文章或项目文档。正文里提到其他内容的标题时，点状下划线表示可以打开。同名时会列出候选，显示类型、标签和创建时间。
3. 在插件详情的「设置」中选择从哪里收录标题、在哪些正文显示，以及使用点状下划线还是背景高亮。勾选卡片后可以在卡片里使用虚拟链接。

在「匹配方式」中，默认只勾选「内容标题」。按需勾选 H1 至 H6，可以同时匹配多个级别，也可以只保留小标题。比如只勾选 H2，另一篇笔记里出现某个二级标题的完整文字时，点击就会跳到那一节。同名小节按所属笔记、级别和位置区分。嵌套在引用块等容器内的小标题会定位到所在的顶层块。

匹配区分大小写，跳过当前内容本身。相同起点有多个标题时优先完整的长标题。英文与数字默认按 ASCII 单词边界匹配，可以在设置里关闭。标题可以跨加粗等文字格式，代码和已有行内链接会隔开匹配范围。新建、改名或删除目标后，索引随资料变化更新。命令面板中的「FakeLink：重新建立索引」可以手动重建索引。

## 用正文找回旧卡片

在「匹配方式」中开启「卡片正文短语」并允许读取卡片。启用时会把卡片加入「在哪些正文显示」，之后可以自行调整。打开文章、项目文档或卡片时，共有的连续短语会自动标出，详情页的「相关卡片」直接显示原句和日期。点击原句打开旧卡片的对应段落。标题与正文短语重叠时保留标题的点击行为。

插件按字面比较连续短语，至少四个字母、数字或汉字，跳过纯数字、常用短词和过于频繁的片段；不推断同义词。卡片不会匹配自身。索引仅保存在当前工作区的运行内存，启用、重启或切库时分页重建，已有结果陆续出现。随后只更新新增、编辑或删除的卡片。关闭此模式会清空正文索引。

## 本地构建

此版本依赖 Tau 桌面主窗口的 `context.textDecorations`。开发用类型随宿主一起打包。在包含这项能力的 Tau 主仓库执行：

```sh
node scripts/plugins/package-sdk.mjs /tmp/tau-fakelink-sdk
```

在本插件的临时工作副本中执行：

```sh
node use-local-sdk.mjs /tmp/tau-fakelink-sdk/*plugins*.tgz /tmp/tau-fakelink-sdk/*ui*.tgz
pnpm install --no-frozen-lockfile
pnpm test
pnpm build
```

安装包位于 `dist/tau.fakelink-0.3.0.zip`。开发版 Tau 的插件页支持在「⋯」中选择「从 ZIP 安装」。普通发行版需随宿主发布这项能力后使用。
